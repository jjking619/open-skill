# 文档一致性检查项清单（Audit Checklist）

> 用法：按顺序过；能脚本化的先脚本化。每条给「判据」与「怎么查」，命中即在报告里给文件 + 位置 + 片段。

## 一、结构（Structure）

| 检查项 | 判据 | 怎么查 |
|---|---|---|
| 宣称 vs 实际 | 目录/功能清单提到的模块，正文是否有对应章节 | 抽目录里的关键词，全文搜索 |
| 漏章 / 多章 | 与同类文档（或上一版本）比章节数 | diff 标题列表 |
| 标题层级 | 不跳级（h2 → h3 → h4） | 正则抓 `^#+` 序列 |
| 空标题 / 空章节 | 标题下无正文 | 标题后到下一个标题之间是否为空 |
| 编号连续 | 手动序号不重不漏 | 抓 `^\d+(\.\d+)*` 序列 |

## 二、链接（Links）

| 检查项 | 判据 | 怎么查 |
|---|---|---|
| 空格与未编码字符 | URL 里不出现空格、中文、`(`, `)` 等 | 正则抓 `\]\(([^)]*)\)` 后检查 |
| 锚点存在 | `#fragment` 能在目标页找到 | 抓标题生成 slug 后比对 |
| 相对路径有效 | 目标文件存在 | 按文档目录解析路径 |
| 外链可达 | HTTP 2xx/3xx | 批量 curl -o /dev/null -w "%{http_code}" |
| 重复定义 | 同一链接文本指向不同 URL | 按文本分组比对 |

## 三、代码块（Code Blocks）

| 检查项 | 判据 | 怎么查 |
|---|---|---|
| 命令与注释粘连 | 一行里 `#` 后跟下一条命令 | 抓 `#\s*\S+ +[a-z]` 类模式 |
| 命令序列挤一行 | `cmd1 && cmd2` 或 `cmd1; cmd2` 出现在示例里且无法一次执行 | 逐行看代码块 |
| 缺语言标注 | ```` ``` ```` 后无语言 | 正则抓围栏行 |
| 围栏配对 | 围栏数为偶数、无嵌套围栏 | 计数 ` ``` ` |
| 提示符残留 | `$ ` / `> ` / `PS> ` 混用 | 抓代码块首字符 |
| 输出与命令混写 | 命令块里夹了执行结果且无注释标记 | 人工抽查 |

## 四、术语与写法（Terminology）

| 检查项 | 判据 | 怎么查 |
|---|---|---|
| 专有名词统一 | 同一对象只有一种写法 | 抽高频名词做变体统计 |
| 全半角统一 | 括号/标点/字母大小写一致 | 正则抓全角括号、大写变体 |
| 中英混排空格 | 按项目既定策略统一（要么都加，要么都不加） | 抓 `[\u4e00-\u9fa5] [A-Za-z]` 与反向 |
| 缩写首次出现 | 首次出现给全称 | 抓缩写在文中的首次位置 |
| 单位与数字 | `5V` vs `5 V`、`10 MB` vs `10MB` | 抓数字 + 单位模式 |

## 五、版式（Layout）

| 检查项 | 判据 | 怎么查 |
|---|---|---|
| 表格列数一致 | 每行列数 = 表头列数 | 解析 `|` 列数 |
| 表格分隔行 | 每张表都有 `|---|` 行 | 正则 |
| 图片说明 | 每张图有图注/替代文本 | 抓图片后一行 |
| 列表嵌套 | 缩进与符号层级一致 | 抓列表行首空白 |
| 修订记录 | 无 `-` / `TBD` / `xxxx` 占位行 | 抽表格首列 |

## 六、镜像一致（Mirror Alignment）

| 检查项 | 判据 | 怎么查 |
|---|---|---|
| 配对完整 | 每个语言版本都能配到对侧 | 按路径/指纹配对，报缺对 |
| 章节数相当 | 两侧标题数差 ≤ 约定阈值 | 抓标题序列比对 |
| 代码块/表格数相当 | 数量一致或差额可解释 | 计数比对 |
| 内容指纹 | 关键段落两侧都存在（非逐字，比指纹） | 取段首关键词搜索对侧 |
| 链接对称 | 两侧指向同一目标 | 抓链接 URL 比对 |

## 问题类型归一化（Finding Types）

用固定枚举，便于统计与批量修：

`structure-missing` · `structure-extra` · `heading-level` · `empty-section` ·
`link-encoding` · `link-anchor` · `link-dead` ·
`code-glue` · `code-lang` · `code-fence` ·
`term-variant` · `spacing` · `unit-format` ·
`table-shape` · `placeholder-leftover` ·
`mirror-missing` · `mirror-mismatch`

> 每条 finding 记录：`文件 | 行 | 类型 | 证据片段（约 20 字符上下文） | 严重级 | 建议`。
> 严重级：🔴 阻断（功能/事实错误）｜🟡 需修（一致性/可读性）｜💡 建议（风格偏好）。
