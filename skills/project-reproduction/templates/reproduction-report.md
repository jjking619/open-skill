## 1. 基本信息
- 复现日期：YYYY-MM-DD
- 原文来源：README / 教程 / install.sh 的路径或 URL
- 源码位置与版本：路径 / git commit / tag
- 目标环境类型：本机 Windows / adb 板子（型号）

## 2. 复现环境
- OS 与版本
- 解释器版本（python3 与 python 分别列出；node 等同理）
- 依赖清单 / 已安装包
- 网络 / 代理 / 权限等特殊配置
- （板子）型号、adb 连接状态、固件版本、根分区剩余空间

## 3. 验收标准
- 用户确认的"跑通"定义：哪条命令、哪种现象、哪个输出算通过
