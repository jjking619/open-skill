# 整仓审查清单（六维 × 分层）

用法：Workflow A3 按层扫描，每层过六维；命中即记
`[级别] 文件:行 — 问题一句话 + 建议`。级别：🔴 阻断 / 🟡 警告 / 💡 建议。

## 分层（按价值排序，L1/L2 必扫）

| 层 | 对象 | 重点 |
|----|------|------|
| L1 | 入口与启动流程 | 参数解析、异常兜底、硬件/驱动/网络缺失时的表现、启动顺序 |
| L2 | 核心业务逻辑 | 算法/主循环/状态机/事件流；与「宣称能力」逐条对照 |
| L3 | 配置/接口/设备访问 | config 读取、串口/GPIO/USB/摄像头/HTTP API、资源释放、超时与重连 |
| L4 | 工具脚本 | install.sh、build、辅助脚本：可复现性、幂等性、错误处理 |
| L5 | 测试与 CI | 能否跑、覆盖关键路径、CI 是否真在跑 |

## 六维清单

### 1. 正确性
- [ ] 边界：空输入、满数据、除零、超时、并发/重入、断连恢复
- [ ] 错误路径：异常被吞？失败有提示？资源释放（文件/设备/连接/线程）？
- [ ] 状态机：非法状态转换、复位后状态残留、看门狗/心跳缺失
- [ ] 宣称 vs 实际：README/注释说的行为与代码一致（不一致 = 🟡 起步）

### 2. 安全
- [ ] 硬编码密钥/口令/证书 —— **含测试目录与示例**，历史 commit 也要查
- [ ] 内网 IP、个人路径痕迹（Windows 用户名 /home/xxx）——发布前清零项
- [ ] 注入：SQL / shell 拼接 / eval/exec 用户输入 / pickle 反序列化 / yaml.load(非 safe)
- [ ] 路径穿越、任意文件写、下载内容未校验（教程里的 curl|sh）
- [ ] 依赖漏洞（pip-audit / npm audit）；关闭证书校验（verify=False / ssl 关）
- [ ] 默认口令/后门/隐藏远程开关

### 3. 代码质量
- [ ] 命名语义化、函数职责单一、魔法数
- [ ] 死代码、未用依赖、重复实现（可合并）
- [ ] 注释与代码不符、整段注释掉的代码
- [ ] 复杂度：超长函数、深嵌套（>4 层）、全局可变状态、隐式依赖

### 4. 测试
- [ ] 有测试吗？能跑吗（`python -m pytest -q` 等）？基线通过数
- [ ] 关键路径用例：失败/异常/边界/断连，而非只有 happy path
- [ ] 是否依赖真实硬件/网络无 mock（嵌入式/硬件 demo 高发，注明即可不强制）

### 5. 性能
- [ ] 循环内重复 IO/日志/图像处理/查询（N+1）
- [ ] 大对象常驻（摄像头帧、模型、缓存无上限）
- [ ] 常驻线程/进程泄漏、启动过慢

### 6. 文档与工程化
- [ ] README 命令可复现（照着跑能通）；教程路径与真实入口一致
- [ ] LICENSE 存在且与声明一致；README 许可证徽章与文件不符 = 🟡
- [ ] .gitignore 漏大文件/密钥/日志？CI 配置存在但从不跑？
- [ ] 依赖锁版本？版本号/CHANGELOG/release 策略？

## 按语言速查

### Python
print/debugger 残留、裸 `except:`、`open()` 无 with、全局可变、
requirements 未锁版本、`sys.path` hack、路径 `\\` 硬编码、
`yaml.load`、`subprocess shell=True`、`requests verify=False`

### C / 嵌入式
缓冲区：`strcpy/sprintf/gets`、`malloc` 未释放、中断/定时器/看门狗未复位、
magic 寄存器直写无注释、平台宏泄漏进业务层、硬编码引脚/地址

### Shell
无 `set -e`、`rm -rf $VAR` 未判空、`curl|sh`、绝对路径假设、
`sudo` 使用无提示、install.sh 非幂等（重复执行会坏）

### JS/TS
`console.log` 残留、`any` 滥用、`innerHTML` 拼用户输入、
未捕获 promise rejection、依赖未锁（无 lockfile）

## 嵌入式/AI demo 专项（板卡类 demo 仓库高频）
- [ ] 模型文件来源：仓库里没有的话，README/install.sh 是否说明下载方式与校验？

- [ ] 出厂默认终端能否直跑：默认 shell 假设、绝对路径解释器
- [ ] 权限：/dev 访问、udev 规则是否随 install.sh 配好
- [ ] 8G 根分区类空间约束：依赖/模型是否装到非系统盘或可配置路径
